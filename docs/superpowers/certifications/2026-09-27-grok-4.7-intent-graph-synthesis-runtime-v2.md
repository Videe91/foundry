## Why a second run exists

The runtime-v1 run failed mainly because Grok listed context objects (the parent Intent and the
served Goal) in `unchanged_object_refs`. That happened in 19 of 23 answers. The v1 prompt never
said that a witness must itself already represent the claim, so the failure was partly a
contract ambiguity. Commit `3499b38` clarified the contract without adding semantics:

- **Witness scope.** `unchanged_object_refs` lists only an existing object that itself already
  represents a meaning asserted by the claims. A parent Intent, a served Goal, an unaffected
  NonGoal or any context object never qualifies.
- **Correction.** The dispositions are PARAPHRASE → witness, CORRECTION → `REPLACES_STALE` with
  no parallel node, NEW → a node, and UNRESOLVED → a gap.
- **Retired objects.** A `REPLACES_STALE` target may not be referenced anywhere else in the
  same answer. `RETIRING_TARGET_REFERENCED` is unchanged.
- **Scorer consistency.** All eight scorers now use one exact-witness rule. Previously cases C
  and F tolerated context witnesses that the other scorers rejected.

## Caveat: case C substrate defect

The stale object `REQ-old` says *"Refund requests are accepted within 30 days of purchase."*
That describes a **request window**. The superseded claim and its correction ("Refunds must
complete within thirty → fourteen calendar days") describe **completion time**. The stale
object therefore never represented the corrected claim's meaning, and a NEW answer is a
defensible reading.

This defect is not scored away. The recorded verdict stands, and it would stand anyway because
of A2 and E1. Fixing the substrate is an exam-design decision and is out of scope for this task.
